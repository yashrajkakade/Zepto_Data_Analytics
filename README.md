# Zepto Data Analytics SQL Project

A SQL-based data analytics project on Zepto product inventory data. This project covers data exploration, data cleaning, and business-focused analysis using PostgreSQL.

## Key Analyses

* Data quality and null value checks
* Inventory availability analysis
* Product and category exploration
* Discount and pricing analysis
* Revenue estimation by category
* High-value product identification
* Price-per-gram evaluation
* Product weight segmentation
* Inventory weight analysis

## Tools Used

* PostgreSQL
* SQL

## Project Objective

To extract actionable business insights from Zepto's product catalog and inventory data through structured SQL queries and analytical reporting.
